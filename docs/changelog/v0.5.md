## 2026-10-09：所选平面拼接 v1

原始来源：`docs/development/selected_plane_stitch_v1.md`（整理前工作区文本）；正文描述当次状态，当前细节可能已替代。

<a id="evidence-0001"></a>

主模块30，复用60选面、50转换、10读取/事务、20画布。整帧拼接保留回滚基线；新入口只处理用户逐帧指定的同一物理平面。

<a id="evidence-0002"></a>

**使用方式**

<a id="evidence-0003"></a>

1. pointcloudview：“工具 → 所选平面拼接”。指定共用手眼XML和输出根目录，按扫描顺序添加PLY。
2. 每帧填写Start/End `[X Y Z A B C]`（mm/deg，A=Rx/B=Ry/C=Rz），选择一行后“加载当前帧 / 重选”。显示模块50转换后的robot_base点云。
3. 同一物理平面上选择三个不重复、非共线点。第三点后完整拟合、分类和连通域提取，成功自动加入；高亮和列表显示点数/RMS，日志显示法向。不进入第二组三点、WObj1、ROI、扫描规划或临时工件输出。
4. 逐帧完成后“拼接所选平面”。勾选“位姿直拼对照”可对相同所选点输出不含精配准的对照。
5. 自动创建 `selected_plane_v1_yyyyMMdd_HHmmss_zzz` 子目录，同名目录存在时追加版本号。模块默认拒绝覆盖，原始输入不修改。

<a id="evidence-0004"></a>

选择只在会话内保存，关闭丢失。不满三点时可以撤销控制点；没有待选点时撤销移除当前行选择。重选失败/取消保留旧选择，切帧保留已加入的所选快照，释放当前整帧计算数据。位姿修改使对应行失效，标定路径修改使全部失效；重排保留所选快照但旧输出不再代表当前顺序。后台运行禁止编辑/切帧，允许取消；关闭先取消并等待，revision不匹配结果不发布。会话假定磁盘输入稳定，不自动监视外部文件内容变化；原PLY/XML被外部修改后应重新加载并选面。输出已经在robot_base，不应再次按原始线扫相机点执行手眼转换。

<a id="evidence-0005"></a>

**接口与算法**

<a id="evidence-0006"></a>

新增独立 `pcv::stitching::SelectedPlaneStitchRequest/Result`、`stitchSelectedPlanes()`；输入为已在robot_base的有序所选点、sourceIndices、scanRatios、三个控制点原始索引、拟合模型和原始转换元数据，不再次手眼转换。应用完成60→30类型映射，30不新增对60依赖。

<a id="evidence-0007"></a>

选面复用 `pcv::planefitting::fit()`，初始1 mm、最终当前平面设置；垂直残差 `useZAxisResidual=false`，任意方向包括垂直面，保留种子连通区域。旧临时工件默认值不改变。

<a id="evidence-0008"></a>

局部u/v/n重叠窗口加3 mm容差，以实际近邻对应求解，不由全局XYZ零厚度否定平面。两层体素0.5/0.2 mm、半径3.0/0.6 mm、迭代20/15，每层至少100对应。目标法向固定为所选模型，噪声不提供额外自由度。

<a id="evidence-0009"></a>

关于目标平面参考中心，绝对状态仅含两个切向轴旋转和法向位移。复用特征值分解，阈值1e-3，仅求有效方向；平面内位移/绕法向旋转固定。连续三次增量≤0.005 mm/0.0005°提前结束。每对10 mm/1°预算；平移预算检查刚体矩阵平移列，包括绕中心旋转产生的平移。

<a id="evidence-0010"></a>

原始相邻帧求P[i]，顺序累计 `C[i]=C[i-1]*P[i]`。无重叠、少对应、无解、超预算弃用该对修正，当前帧累计矩阵重置单位，警告后继续。累计不限但报告；每个所选完整点只变换一次，按帧序/原点序合并。保留实测起伏和重叠双份采样，不投影/平均/去重/seam/preview。

<a id="evidence-0011"></a>

`degenerate=true`表示完整6DoF没有被观测，是单平面路径的正常诊断；开放方向数另外记录。低覆盖/退化/迭代上限只警告。输入、转换、索引、非有限、内存、取消和事务错误仍终止，不发布部分正式输出。

<a id="evidence-0012"></a>

worker只读const共享容器，返回私有对应片段，future全汇合后按点序归并。pair求解及累计提交顺序执行。MainWindow仅包含轻量launcher，避免旧processor与模块30同名ICP DTO头文件冲突。

<a id="evidence-0013"></a>

**输出和计时**

<a id="evidence-0014"></a>

10 `ArtifactTransaction` 成套提交 `selected_plane_robot_base.ply`、`selected_plane_robot_base.pcvmap`、`selected_plane_manifest.json`。PLY binary little-endian；map沿用v1：magic `0x314D4350`、版本1、点数，随后cloudId/int32、sourceIndex/int64、scanRatio/float32。

<a id="evidence-0015"></a>

`processing_mode=selected_plane_stitch`、`quality_policy=warn_only`、`strict_validation_status=not_run`。formal_output仅为事务成功。逐帧保存转换矩阵、模型、RMS、点数和控制点原始索引；逐对保存应用/回退、原因、层数/迭代/对应/残差/可观测自由度、pair和累计矩阵/漂移。旧accepted、结构3 mm覆盖为null，不假称通过。

<a id="evidence-0016"></a>

`selection_ms`从第三点触发的worker开始执行至拟合、分类和快照组装完成，不包含人工思考、点击、任务排队和GUI绘制；registration/merge分别记录求解和全点组装。持久报告 `output_stage_ms` 为PLY/map staging，`total_precommit_ms` 截止manifest提交前，timing_scope说明不包括manifest staging和commit。返回结果另给准确output_commit_wall_ms/total_wall_ms；不在事务后覆写manifest来伪装成原子计时记录。交互到显示的真实耗时留待现场性能验证。

## 2026-10-15：共享拼接 UI

<a id="evidence-0026"></a>

**实现与边界**

<a id="evidence-0027"></a>

- 新增应用层静态库 `pcv_stitching_ui`，共享 `StitchingWindow`、Designer UI、输入编辑、参数映射、后台任务、取消、进度、日志和覆盖确认。算法模块不反向依赖此库。
- 两个 GUI 应用共同链接共享库；根 CMake 仅在任意 GUI 应用开启时加入该目录。保留 `PCV_BUILD_POINTCLOUDSTITCH` 和独立应用 target。
- `pointcloudview` 的“工具 → 多帧点云拼接”和“多帧配准...”按钮复用同一独立非模态窗口。子窗口关闭只隐藏并保留输入、日志和任务；主窗口退出先取消并等待。
- `pointcloudstitch` 直接创建同一个共享窗口；独立应用关闭时取消并等待。原窗口头保留 forwarding，原 cpp 只保留兼容说明，原 `.ui` 不再参与编译；共享目录内 `.ui` 是维护入口。
- 原 `RegistrationDialog` 文件保留，但不再编入 `pointcloudview`。`regressionrunner` 命令及应用 processor wrapper 保留，不改变既有回归报告契约。
- 普通区显示抽样步长、预览保留率、seam 开关/半宽；其他现有控件进入可折叠“高级设置”。保留当前完整配准/仅手眼转换两模式及其默认值，不恢复已回滚的 `PoseOverlapFine`。
- 文件输入支持排序、去重、递归文件夹扫描、整行上下移动和删除；移动时 Start/End 位姿随行移动。位姿仍为 `[X,Y,Z,A,B,C]`，拒绝非有限值。

## 2026-10-15：单击选面完整性 v2

原始来源：`docs/development/single_click_plane_selection_v2.md`（整理前工作区文本）；正文描述当次状态，当前细节可能已替代。

<a id="evidence-0066"></a>

日期：2026-10-15。主模块：`60_geometry_workpiece`；UI：`apps/pointcloudview`。v1 历史记录保留。本轮真实样本和 GUI 视觉验收由用户完成。

<a id="evidence-0067"></a>

**问题与行为**

<a id="evidence-0068"></a>

用户反馈平面会被扫描条带或孔洞截断。v1 的首轮空间网格范围会永久限制后续分类，连接半径只按点击邻域面积/点数计算，混入侧面的网格被整体拒绝，因而无法补齐部分真实平面。

<a id="evidence-0069"></a>

v2 每轮按当前模型重新筛选全帧距离容差内的点，先建立正常采样连通域，再按真实边界点的投影距离连接缺失带两侧区域。用户参数“最大跨缺失距离”默认 3 mm，范围 0～50 mm；0 只关闭额外跨带，正常采样连接保留。最终点始终满足现有垂直距离容差，不自动放宽、不补点、不压平、不改变点序或 source index。

<a id="evidence-0070"></a>

单击模式可编辑跨带参数，三点模式禁用；更改参数使当前候选失效，保留已确认选择，重新点击后生效。预览确认、自动下一帧、取消和 revision 门禁保持原语义。

<a id="evidence-0071"></a>

**算法**

<a id="evidence-0072"></a>

- 固定种子 RANSAC/PCA 比较多个尺度，保留较大稳定邻域模型；从最近邻主方向估计平面内两个方向的采样间距，正常连接采用方向独立的半径。
- 只读空间索引在帧准备阶段缓存邻域模型。明确平整且与目标面显著不同向的邻域仅提供逐点归属判断：只有点到目标面的距离比到局部面的距离大于用户容差的四分之一时才排除。混合/共线邻域保留满足模型距离的原始点，不整格删除折边附近的真实目标点。
- 正常连接以方向归一化距离判定；跨带阶段在区域边界建立投影索引，每次合并必须存在真实边界点对，其欧氏投影距离不超过 maximumGapMm。网格、包围盒和空白膨胀不作为合并依据。
- 模型拟合只使用已选区域，对最高残差部分进行稳健裁剪，仅影响模型估计，最终分类仍使用完整用户容差；重新分类/连通最多六轮，点索引集合稳定时停止。达到轮数上限也只返回满足发布模型容差的点，不以超时提前截断。
- worker 只读取 const 共享容器，私有结果全部 join 后按输入顺序合并；取消不返回可发布的部分点集。
- 投影网格的点链和邻接表使用连续数组，避免每格分配两个小型容器；每轮在当前模型平面内建立正交投影轴。只有精化后全帧候选索引和模型法向均完全相同时，才复用连通结果，不重复搜索，不以时间阈值裁剪点集。
