# 当前需求与能力

软件 CMake PROJECT_VERSION 为 1.0.0，已有 JSON/PLY/PCVMAP/schema 名称保持兼容。已实现表示存在源码，不表示真实设备、性能或部署全部验收。

| 入口 | 保留能力 |
|---|---|
| pointcloudview | 点云查看、过滤、整帧/所选平面拼接、相机/RAW/连续采集、临时工件、ROI/WObj1、纹理、扫描轨迹与模板 |
| scan_geometry_demo_v1 | PLY/深度帧输入、选面与参考匹配、人工审核、干涉区域、拼接、修剪/撤销/恢复、WObj1、几何保存 |

完整实测点集用于计算与输出，展示抽样不截断业务数据。候选须人工确认；所选平面 warn_only，formal_output 仅表示事务成功。
